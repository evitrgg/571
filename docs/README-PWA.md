# מעקב בגרויות 571 — גרסת PWA (אפליקציית אינטרנט)

אותה אפליקציה כמו גרסת האנדרואיד, שרצה בדפדפן ומותקנת על המסך הבית (iPhone + Android).

## העלאה ל-GitHub Pages (בחינם)
1. בריפו `evitrgg/571` צור תיקייה `docs` והעלה אליה את **כל** הקבצים והתיקיות האלה: `index.html`, `app.js`, `data.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
2. ב-GitHub: Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main`, תיקייה: `/docs` ← Save.
3. אחרי דקה-שתיים הקישור יופיע שם (בצורה `https://evitrgg.github.io/571/`). זה הקישור שמשתפים.

## התקנה אצל המשתמשים
- **iPhone**: לפתוח את הקישור ב-Safari ← כפתור שיתוף ← "הוסף למסך הבית".
- **Android**: Chrome ← "התקן" (או הכפתור בבאנר באפליקציה).

## קובץ ה-PDF
הדפדפן חוסם הורדה אוטומטית משרת gool (CORS), לכן יש שתי דרכים שעובדות בוודאות:
- **לשים את ה-PDF בתוך `docs`** (למשל `571.pdf`), ובהגדרות באפליקציה לכתוב בשדה הקישור `571.pdf`. אז ההורדה עובדת לכולם בלחיצה אחת, בפעם הראשונה בלבד.
- או שכל משתמש שומר את הקובץ בטלפון ובוחר אותו דרך **הגדרות ← בחר קובץ PDF מהמכשיר** (או כפתור "בחר קובץ" שמופיע אם ההורדה נכשלת).

(כדאי לוודא שמותר לך לארח את הקובץ.) כדי שכל המשתמשים יקבלו את הקישור כברירת מחדל, אפשר לשנות את `GOOL_URL` בראש `data.js` ל-`"571.pdf"`.

## עדכון האפליקציה
אחרי שינוי בקבצים, להחליף את שם הגרסה ב-`sw.js` (שורה 1: `bagrut-v1` ← `bagrut-v2`) כדי שהמכשירים יתעדכנו.

## הערות
- ההתקדמות, ההערות והתמונות נשמרות במכשיר (IndexedDB). בהגדרות יש **גיבוי/שחזור** לקובץ, כי ב-iPhone Safari עלול למחוק נתוני אתר שלא נפתחו זמן רב.
- הספרייה pdf.js נטענת מ-cdnjs בפעם הראשונה ונשמרת לעבודה offline.
